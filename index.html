Welcome to Forge Logic

How to get started:

  1. Open Parts and add gates or chips.
  2. Click an output pin, then an input pin to connect.
  3. Use Snapshot to save a sheet as a chip.
  4. Pick a lesson on the right → Start → build → Submit.

Shortcuts: Ctrl+Z undo · Ctrl+A select all · Shift+drag marquee · Ctrl+C/Ctrl+V copy/paste · Ctrl+D duplicate · Esc stop connecting · arrows move node.

On iPhone/iPad, export your project as a file now and then (Safari may clear site data for rarely used sites).
